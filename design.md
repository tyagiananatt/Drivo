29. Animation Rules

Keep animations smooth and premium, not flashy.

Use:

Framer Motion
GSAP
Three.js / React Three Fiber
Lenis

for a React/Next.js implementation.

Recommended behavior

Page load:

Fade + slide.

Scroll:

Parallax + scale + 3D rotation.

Hover:

Small elevation.

Cards:

Very subtle tilt.

Numbers:

Count from 0 → actual number.

Charts:

Draw when entering viewport.

Vehicle:

Slow rotation tied to scroll progress.
